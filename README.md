# Tributo Fácil

Repositório organizado em duas aplicações independentes:

- **`backend/`**: API e painel CMS em Strapi.
- **`frontend/`**: Aplicação web em Vite + TypeScript puro + CSS puro (MPA).

Consulte a proposta completa em [PROPOSTA.md](./PROPOSTA.md).

## Como rodar

### Backend (Strapi)
```bash
cd backend
npm install
npm run develop
```

### Frontend (Vite)
```bash
cd frontend
npm install
npm run dev
```
